# Submarine Tracker

追蹤與管理公會潛水艇的插件，支援多間公會、多名角色。

原作者：[Infiziert90/SubmarineTracker](https://github.com/Infiziert90/SubmarineTracker)

## 功能

- 追蹤器：顯示目前配置、航行路線、返航時間
- 建造器：協助優化配置、規劃練級路線、提升經驗效率
- 可設定的返航／維修聊天提醒
- 速查（Helpy）：常用資訊一覽，含倉庫存量
- 自訂戰利品總覽：歷史紀錄，可匯出 CSV
- 多組疊加視窗，方便查看下一趟航行、路線與返航倒數

## 指令

- `/stracker`：開啟追蹤器
- `/sbuilder`：開啟建造器
- `/sloot`：開啟戰利品總覽（`/sloot copy` 依目前設定將歷史紀錄匯出為 CSV 至剪貼簿）
- `/shelpy`：開啟速查視窗
- `/sconf`：開啟設定
- `/soverlay`：開啟／關閉返航疊加層
